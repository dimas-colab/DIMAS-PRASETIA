# Urban Planning Portfolio - Dimas Prasetia

Professional portfolio website for **Dimas Prasetia**, Bachelor of Urban and Regional Planning. 
Designed with a "Kementerian BUMN" (Ministry of SOE) corporate aesthetic to demonstrate professionalism, reliability, and institutional alignment.

## Project Overview

-   **Owner**: Dimas Prasetia
-   **Role**: Urban & Regional Planner | GIS Analyst
-   **Tech Stack**: React 19, Vite, Corporate CSS Design System.

## Design Concept

This website strictly adheres to an "Official Government/Corporate" identity:
-   **Color Palette**: Ministry Blue (`#002B5C`) & Gold Accents (`#fdc500`).
-   **Typography**: Official Sans-serif (`Roboto` / `Inter`).
-   **Layout**: Full-width banners, sticky navigation, and "Public Information" style cards.

## Deployment

The project is optimized for deployment on **Vercel** as a Single Page Application (SPA).

### Local Development
1.  Install dependencies: `npm install`
2.  Run server: `npm run dev`
3.  Build for production: `npm run build`
